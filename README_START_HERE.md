# Blockcraft handoff kit

1. **KICKOFF_PROMPT.md**: the message to start the new session with (attach this zip).
2. **HANDOFF.md**: the full brief: working rules, design rules, current state, open items, traps, testing, code map.
3. **game/blockcraft.html**: the latest build (2026-11-14). Open it in Chrome.
4. **docs/**: task log (newest sections at the bottom), game plan, feature notes, playtest list, village ideas.
5. **tests/**: the regression suite and every test/tool script; start with `tests/README.md`.
6. **images/**: 1080p before/after of the renderer, a full 1080p GPU frame, and an overview of 66 feature
   screenshots (taken with the old CPU renderer).
